Zelefin

Settings here apply to every Zelefin install signed in to this server. Users do not have to type a Seerr URL or password on their phones.

Seerr
Seerr → Settings → General → API Key. Paste this once. Zelefin then signs each Jellyfin user in automatically — no password on the phone. Leave blank when saving if the key is already stored.
Intro Skipper
When locked, Zelefin uses these values and hides the toggles. When unlocked, they are defaults only.
iPhone notifications

Alerts are sent through Zelefin’s push service. You do not need an Apple Developer account. Phones register themselves after sign-in; use the Notifications tab for event toggles.
